Create the shared theme infrastructure:

1. **src/components/theme/types.ts** — Define:
   ```typescript
   export type Theme = "light" | "dark" | "system";
   export const MONARCA_APP_THEME_KEY = "monarca-app-theme";
   export const MONARCA_ADMIN_THEME_KEY = "monarca-admin-theme";
   export interface ThemeContextType {
     theme: Theme;
     resolvedTheme: "light" | "dark";
     setTheme: (theme: Theme) => void;
   }
   ```

2. **src/components/theme/useTheme.ts** — Create hook that:
   - Accepts a `storageKey` prop (either `MONARCA_APP_THEME_KEY` or `MONARCA_ADMIN_THEME_KEY`)
   - Reads initial value from `localStorage.getItem(storageKey)`
   - Falls back to `"system"` if no localStorage value
   - Listens to `storage` events for cross-tab sync
   - Computes `resolvedTheme` from OS preference when `theme === "system"`:
     ```typescript
     window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light"
     ```
   - Watches `prefers-color-scheme` changes via `addEventListener("change", ...)` when in "system" mode
   - Returns `{ theme, resolvedTheme, setTheme }`
   - `setTheme` writes to localStorage AND dispatches a `storage` event for same-tab sync
   - MUST be used inside a ThemeProvider (use React.useContext)

3. **src/components/theme/ThemeScript.tsx** — Create a React component that renders an **inline script**:
   - Props: `surface: "app" | "admin"`
   - Renders `<script dangerouslySetInnerHTML={{ __html: script }} />`
   - The script logic (as a string):
     ```javascript
     (function() {
       var key = surface === "app" ? "monarca-app-theme" : "monarca-admin-theme";
       var root = document.querySelector(surface === "app" ? ".app-shell" : ".admin-layout");
       var stored = localStorage.getItem(key);
       var theme = stored || "system";
       var resolved = theme === "system"
         ? (window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light")
         : theme;
       if (root) {
         root.setAttribute("data-theme", resolved);
       }
     })();
     ```
   - IMPORTANT: The script must be self-executing and run immediately on parse. Do NOT wait for DOMContentLoaded.
   - The script is injected into the HTML by the server layout (next task) so it executes before React hydrates.

Use TypeScript strict mode. No `any` types. Export all public APIs.
