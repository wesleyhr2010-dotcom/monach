### Timezone Pattern (from actions-analytics.ts)
```typescript
const PY_OFFSET_MS = 3 * 60 * 60 * 1000; // UTC-3
function getSinceDate(days: number): Date {
  const nowPy = new Date(Date.now() - PY_OFFSET_MS);
  nowPy.setUTCDate(nowPy.getUTCDate() - days);
  nowPy.setUTCHours(0, 0, 0, 0);
  return new Date(nowPy.getTime() + PY_OFFSET_MS);
}
```

### URL Range Pattern (from actions-analytics.ts)
```typescript
export async function getRangeFromParams(
  period?: number,
  fromStr?: string,
  toStr?: string
): Promise<{ from: Date; to: Date }> {
  if (fromStr && toStr) {
    const from = new Date(`${fromStr}T00:00:00-03:00`);
    const to = new Date(`${toStr}T23:59:59.999-03:00`);
    return { from, to };
  }
  const days = period ?? 30;
  const from = getSinceDate(days);
  const to = new Date();
  to.setHours(23, 59, 59, 999);
  return { from, to };
}
```

    **1. listVentas(params): ActionResult<{ items: VentaListItem[]; totalCount: number }>**
    - Validate `requireAuth(["ADMIN"])`
    - Build `where` clause with `created_at: { gte: from, lte: to }`
    - If `search` provided (non-empty after trim): add `cliente: { OR: [{ nombre: { contains: search, mode: "insensitive" } }, { ruc: { contains: search, mode: "insensitive" } }] }` — this naturally excludes `cliente_id: null` (Consumidor Final) because the relation won't match

    - Pagination: `skip: (page - 1) * pageSize`, `take: pageSize` (default page=1, pageSize=20)
    - Sorting: `orderBy` based on `sort` param. For `cliente`, sort by `cliente.nombre`. Default `created_at desc`.

    - Map results to `VentaListItem`:
      - `cantidad_itens`: `venta.itens.length`
      - `total`: `Number(venta.total)`
      - `total_pyg`: `Number(venta.total_pyg)`
      - `cliente_nombre`: `venta.cliente?.nombre ?? null`
      - `cliente_ruc`: `venta.cliente?.ruc ?? null`
    - Run count query in parallel with findMany using `Promise.all`
    - Return `{ items, totalCount }`

    **2. getVentaById(id: string): ActionResult<VentaDetalhe>**
    - Validate `requireAuth(["ADMIN"])`
    - Find unique `VentaLoja` with `cliente`, `itens: { include: { product_variant: { include: { product: true } } } }`

      - `total`, `total_pyg`, `precio_unitario`, `subtotal`: use `Number()`

    - Return mapped object

      const [ventaAgg, itemAgg] = await Promise.all([

          where,
          _sum: { total_pyg: true },
          _count: { id: true },

    function buildVentasWhere(params: { from: Date; to: Date; search?: string }) {
