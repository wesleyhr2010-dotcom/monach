## Key patterns from codebase

**Existing cart library:**
- `src/lib/cart.ts` — `getCart()`, `addToCart()`, `removeFromCart()`, `clearCart()`, `CART_UPDATED_EVENT = "cart-updated"`, `localStorage` with `try/catch` guards
- Pattern: `typeof window !== "undefined"` before localStorage access
- Pattern: `window.dispatchEvent(new CustomEvent(CART_UPDATED_EVENT))` after writes

**Locked decisions:**
- **D-14:** Carrinho armazenado em **localStorage**
- **D-15:** Carrinho acessível via **badge flutuante sticky**
- **D-16:** "Finalizar pedido" gera **mensagem formatada** para WhatsApp

**SPEC cart structure:**
```json
{
  "reseller_slug": "ana-silva-a3f",
  "items": [
    {
      "product_variant_id": "uuid",
      "product_id": "uuid",
      "name": "Collar Elegance",
      "price": 125000,
      "quantity": 2,
      "image_url": "https://r2..."
    }
  ],
  "updated_at": "2026-05-05T12:00:00Z"
}
```

**WhatsApp message format (from SPEC):**
```
Hola Ana, vi tu vitrina y me interesan estos productos:

1. Collar Elegance (x2) — G$ 250.000
2. Pulsera Boho (x1) — G$ 85.000

Total: G$ 335.000

¿Están disponibles? 💎
```

**Currency:** Use `formatGs()` from `src/lib/format.ts` — returns "G$ 1.850.000"

**Checkout flow:**
1. Customer clicks badge → drawer opens
2. Drawer shows items with remove button
3. Customer clicks "Finalizar pedido por WhatsApp"
4. Fire `clique_whatsapp` tracking event (POST to `/api/vitrina/track`)
5. Build message with `buildWhatsAppMessage()`
6. Open `https://wa.me/${whatsapp}?text=${encodeURIComponent(message)}`

**Edge cases:**
- Cart empty at checkout → show "Tu carrito está vacío" with link back to vitrina
- localStorage unavailable → cart starts empty, graceful degradation
- Message > 2000 chars → fallback summary message

       - `addToVitrinaCart(item: Omit<VitrinaCartItem, 'quantity'>, resellerSlug: string, quantity = 1)`:
         - Read existing cart

         - Else: find existing item by `product_variant_id`. If found, increment quantity (cap at 10). If not, push new item.
         - Save cart
       - `removeFromVitrinaCart(variantId: string)` — filter out item, save
       - `getVitrinaCartCount(): number` — sum of quantities
       - `getVitrinaCartTotal(): number` — sum of `price * quantity`
       - `buildWhatsAppMessage(cart: VitrinaCart, resellerName?: string): string`:
         - Header: `Hola ${resellerName || ''}, vi tu vitrina y me interesan estos productos:`
         - Lines: `cart.items.map((item, i) => \`${i + 1}. ${item.name} (x${item.quantity}) — ${formatGs(item.price * item.quantity)}\`)`
         - Total line: `Total: ${formatGs(cart.items.reduce((s, i) => s + i.price * i.quantity, 0))}`
         - Footer: `¿Están disponibles? 💎`
         - Full message: `\`${header}\\n\\n${lines.join('\\n')}\\n\\n${total}\\n\\n${footer}\``
         - If `msg.length > 2000`: return `\`${header}\\n\\nVi varios productos en tu vitrina. ¿Podemos hablar?\\n\\n${total}\``
