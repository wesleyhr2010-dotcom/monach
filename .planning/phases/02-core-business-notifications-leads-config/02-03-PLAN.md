  <action>
    1. Check if `src/app/admin/actions-config.ts` exists; if not, create it.
    2. Import `safeAction`, `ActionResult` from `@/lib/action-utils`.
    3. Implement `getCommissionTiers()`:
       - Query `prisma.commissionTier.findMany({ orderBy: { min_sales_value: 'asc' } })`.
       - Return `ActionResult<CommissionTier[]>`.
    4. Implement `upsertCommissionTier(data)`:
       - Validate with Zod schema: `label: z.string().min(2).max(30)`, `min_sales_value: z.number().int().min(0)`, `commission_pct: z.number().min(1).max(100)`.
       - Check for duplicate `min_sales_value` (exclude current ID on update).
       - Ensure at least one tier with `min_sales_value = 0` remains after update.
       - Use `prisma.commissionTier.upsert`.
       - Return `ActionResult<CommissionTier>`.
    5. Implement `deleteCommissionTier(id)`:
       - Check if tier has `min_sales_value = 0` → return error "Não é possível deletar a faixa base".
       - Check if tier is referenced by any closed maleta (if such relation exists; otherwise just delete).
       - Use `prisma.commissionTier.delete`.
       - Return `ActionResult<void>`.
    6. Implement `getNivelRegras()`:
       - Query `prisma.nivelRegra.findMany({ orderBy: { pontos_minimos: 'asc' } })`.
       - Return `ActionResult<NivelRegra[]>`.
    7. Implement `upsertNivelRegra(data)`:
       - Validate with Zod: `nome: z.string().min(2).max(30)`, `pontos_minimos: z.number().int().min(0)`, `cor: z.string().regex(/^#[0-9A-Fa-f]{6}$/)`, `ordem: z.number().int().min(0)`, `ativo: z.boolean()`.
       - Check for duplicate `pontos_minimos` (exclude current ID).
       - Use `prisma.nivelRegra.upsert`.
       - Return `ActionResult<NivelRegra>`.
    8. Implement `deleteNivelRegra(id)`:
       - Check if level is referenced by any reseller progress/gamification data (if relation exists).
       - Use `prisma.nivelRegra.delete`.
       - Return `ActionResult<void>`.
    9. All functions must call `requireAuth(["ADMIN"])`.
    10. Run `npm run typecheck`.
  </action>
