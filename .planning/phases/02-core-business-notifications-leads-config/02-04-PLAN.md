  <name>Task 1: Add contract server actions with R2 upload</name>
  <files>src/app/admin/actions-config.ts</files>
  <action>
    1. Read `src/app/admin/actions-config.ts` (created in Plan 03) to understand existing structure.
    2. Add `getContratos()`:
       - Query `prisma.contrato.findMany({ orderBy: { created_at: 'desc' } })`.
       - Return `ActionResult<Contrato[]>`.
    3. Add `uploadContrato(formData: FormData)`:
       - Use `safeAction` wrapper.
       - Extract file from FormData.
       - Validate: `file.type === 'application/pdf'`, `file.size <= 10 * 1024 * 1024`.
       - Generate UUID for filename.
       - Upload to R2: `contratos/{uuid}.pdf`.
       - Create `prisma.contrato.create({ data: { nome, url, obrigatorio, ativo } })`.
       - Return `ActionResult<Contrato>`.
    4. Add `updateContrato(id, data)`:
       - Validate with Zod: `nome: z.string().min(2)`, `obrigatorio: z.boolean()`, `ativo: z.boolean()`.
       - Use `prisma.contrato.update`.
       - Return `ActionResult<Contrato>`.
    5. Add `deleteContrato(id)`:
       - Find contrato, delete from R2 if URL exists.
       - Use `prisma.contrato.delete`.
       - Return `ActionResult<void>`.
    6. All functions require `requireAuth(["ADMIN"])`.
    7. Run `npm run typecheck`.
  </action>
