<objective>
Establish the error-handling foundation for all Server Actions by enhancing the existing `safeAction()` wrapper with Prisma error mapping and migrating the highest-traffic PWA action file (`actions-revendedora.ts`) to the `ActionResult<T>` pattern.

Purpose: Eliminates ad-hoc `throw new Error("BUSINESS:...")` patterns in the PWA's main action file and provides a reusable, testable error-handling primitive for the rest of the codebase.
</objective>
