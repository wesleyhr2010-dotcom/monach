  <action>
    1. Install recharts: `npm install recharts`
    2. Create `src/lib/date-range.ts` with:
       - `export type TimeRange = 'semana' | 'mes' | '30dias' | 'anio'`
       - `export function getDateRange(rango: TimeRange): { start: Date; end: Date; prevStart: Date; prevEnd: Date }`
       - Compute ranges in `America/Asuncion` timezone. Use `new Date()` for "now", then calculate:
         - semana: start = now - 7 days, end = now; prev = 7 days before start
         - mes: current calendar month (1st to last day); prev = previous calendar month
         - 30dias: rolling 30 days; prev = 30 days before start
         - anio: current calendar year (Jan 1 to Dec 31); prev = previous calendar year
       - All Date objects should have time set to start-of-day (00:00:00) for start and end-of-day (23:59:59.999) for end
    3. Create `src/app/app/actions-desempenho.ts`:
       - Import `requireAuth` from `@/lib/user`
       - Import `prisma` from `@/lib/prisma`
       - Import `getDateRange`, `TimeRange` from `@/lib/date-range`
       - Export `async function getMetricasDesempenho(resellerId: string, rango: TimeRange)`
       - Call `requireAuth(["REVENDEDORA"])` at the top
       - Validate that the authenticated user's `profileId` matches `resellerId` (defense in depth)
       - Compute `{ start, end, prevStart, prevEnd } = getDateRange(rango)`
       - Query in parallel with `Promise.all`:
         a. Current period metrics from `AnalyticsDiario` (for ranges > 7 days) OR `AnalyticsAcesso` (for ≤ 7 days):
            - total_visitas: SUM(total_visitas) from AnalyticsDiario where reseller_id = ? AND data BETWEEN start AND end
            - visitantes_unicos: SUM(visitantes_unicos) from AnalyticsDiario where reseller_id = ? AND data BETWEEN start AND end
            - cliques_whatsapp: SUM(cliques_whatsapp) from AnalyticsDiario where reseller_id = ? AND data BETWEEN start AND end
            - OR for ≤7d: COUNT(*) from AnalyticsAcesso where reseller_id = ? AND tipo_evento = 'catalogo_revendedora' AND data_acesso BETWEEN start AND end
            - visitantes_unicos for ≤7d: COUNT(DISTINCT visitor_id) from AnalyticsAcesso where reseller_id = ? AND data_acesso BETWEEN start AND end
            - cliques_whatsapp for ≤7d: COUNT(*) from AnalyticsAcesso where reseller_id = ? AND tipo_evento = 'clique_whatsapp' AND data_acesso BETWEEN start AND end
         b. Previous period metrics (same queries with prevStart/prevEnd)
         c. Daily visits for chart: SELECT data, total_visitas FROM AnalyticsDiario WHERE reseller_id = ? AND data BETWEEN start AND end ORDER BY data ASC
         d. Top 10 products: SELECT produto_id, COUNT(*) as visitas FROM AnalyticsAcesso WHERE reseller_id = ? AND tipo_evento = 'catalogo_revendedora' AND data_acesso BETWEEN start AND end GROUP BY produto_id ORDER BY visitas DESC LIMIT 10. Then join with Product/ProductVariant to get names and images.
         e. Pieces sold: COUNT(*) FROM VendaMaleta WHERE maleta.reseller_id = ? AND created_at BETWEEN start AND end
       - Return type: `{ actual: Metrics, anterior: Metrics, variacao: Variacao, grafico: GraficoPoint[], productos: ProductoPop[] }`
       - Metrics shape: `{ accesos: number, visitantes_unicos: number, cliques_whatsapp: number, pecas_vendidas: number }`
       - Variacao shape: `{ accesos_pct: number | null, visitantes_pct: number | null, cliques_pct: number | null, pecas_pct: number | null }` (null when anterior = 0)
       - GraficoPoint shape: `{ dia: string, visitas: number }` (dia formatted as "L", "M", "X", etc. for semana; "16/Abr" for mes/anio)
       - ProductoPop shape: `{ id: string, nome: string, imagem_url: string | null, visitas: number }`
  </action>

| Client → Server Action | Untrusted client requests metric data |
| Server Action → Database | Queries must be scoped to authenticated reseller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | getMetricasDesempenho | mitigate | Validate profileId matches resellerId parameter; query WHERE reseller_id = authenticated user's profileId |
| T-03-02 | Tampering | TimeRange parameter | mitigate | Validate rango against union type; reject invalid values; default to 'semana' |
| T-03-03 | DoS | Analytics queries | mitigate | Use AnalyticsDiario (pre-aggregated) for ranges > 7 days; LIMIT 10 on product queries; index on reseller_id + data_acesso |
| T-03-04 | Information Disclosure | Empty state message | accept | Low risk — empty state reveals only that user has no data, which is expected for new users |
</threat_model>
