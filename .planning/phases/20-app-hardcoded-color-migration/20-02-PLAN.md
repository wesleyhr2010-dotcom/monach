    | border-[#D9D6D2] | border-app-border-strong |

    **Special cases:**
    - `text-white` → KEEP as-is (correct in both themes)
    - `style={{ color: "#..." }}` → Replace with equivalent Tailwind class
    - `style={{ backgroundColor: "#..." }}` → Replace with equivalent Tailwind class
    - Any `bg-[#...]/10` opacity syntax → Map to `bg-[token]/10` (e.g., `bg-[#35605A]/10` → `bg-app-primary/10`)

    For **loading.tsx**: The spinner uses `borderColor: "#EBEBEB"` and `borderTopColor: "#35605A"` in inline style. Replace with Tailwind classes: `border-app-surface` and `border-t-app-primary` on the spinner element, removing the inline style.
