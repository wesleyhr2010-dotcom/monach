       - Line ~134: `style={{ backgroundColor: isReadOnly ? "#FFF4E5" : "#E2F2E9" }}` — This is a critical inline style with conditional colors.
         - Replace the entire inline style with a computed className string:
           ```tsx
           className={isReadOnly ? "bg-app-warning-bg" : "bg-app-accent-green-bg"}
           ```
         - Remove the `style={{ backgroundColor: ... }}` prop entirely.
       - Photo preview area may have `bg-[#F5F2EF]` → `bg-app-bg`
       - Status colors on items → map to semantic tokens

    3. **layout.tsx files (both devolver and registrar-venta):**
       - `style={{ backgroundColor: "var(--motion-sheet-handle-bg, #E0DDD8)" }}` — This is a motion sheet handle background.
       - The inline style references a CSS variable with a fallback hex. Keep the CSS variable but ensure `--motion-sheet-handle-bg` is properly tokenized.
       - In globals.css, `--motion-sheet-handle-bg` is currently `var(--color-app-divider, #F5F2EF)`. This is already using a token! The fallback `#E0DDD8` in the inline style is just a secondary fallback. Since the CSS variable should resolve to the token, we can keep this inline style as-is because it uses `var()` and the actual color comes from the token system.
       - **Decision:** Keep the motion sheet handle inline styles unchanged. The color is controlled by the CSS variable which references the token.
