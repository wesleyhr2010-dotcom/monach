<objective>
Add cache invalidation (revalidateTag / revalidatePath) to every mutation Server Action. Create a centralized invalidateCache helper to avoid scattering cache tags across the codebase.

Purpose: Prevent stale data on ISR pages and cached queries after mutations. When admin updates a product, the catalog cache must refresh. When a revendedora closes a maleta, her commission cache must refresh.
Output: invalidateCache helper + all mutation actions calling it after successful writes.
</objective>

       ```ts
       import { revalidateTag, revalidatePath } from "next/cache";

       export const invalidateCache = {
         // Commission for a specific reseller
         commission: (resellerId: string) => revalidateTag(`commission-${resellerId}`),

         // Product catalog (public pages)
         catalog: () => revalidateTag("catalog"),

         // Brindes catalog
         brindes: () => revalidateTag("brindes"),

         // Gamification rules config
         gamificacaoConfig: () => revalidateTag("gamificacao-config"),

         // Public vitrine page for a reseller
         vitrine: (slug: string) => revalidateTag(`vitrine-${slug}`),

         // Commission tiers config
         tiersConfig: () => revalidateTag("tiers-config"),

         // Niveis (gamification levels) config
         niveisConfig: () => revalidateTag("niveis-config"),

         // Admin dashboard KPIs
         adminDashboard: () => revalidateTag("admin-dashboard"),

         // Reseller performance dashboard
         desempeno: (resellerId: string) => revalidateTag(`desempeno-${resellerId}`),

         // Generic path revalidation helpers
         path: {
           product: (slug: string) => revalidatePath(`/produto/${slug}`),
           catalogo: () => revalidatePath("/catalogo"),
           vitrina: (slug: string) => revalidatePath(`/vitrina/${slug}`),
           admin: (path: string) => revalidatePath(`/admin${path}`),
           app: (path: string) => revalidatePath(`/app${path}`),
         },
       };
       ```

       - All cache invalidation MUST go through this helper
       - When adding a new cached query, add its invalidation method here
       - Tags must match those used in `unstable_cache` calls exactly
