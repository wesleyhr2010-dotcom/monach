       - Implement `getEmailOverride(tipo: string)` wrapped in `React.cache` per D-14 and Pattern 1.
       - Implement `getEmailContent(tipo: string, context: Record<string, any>)` helper.
       - This helper should follow these decisions:
         a. Fetch override from DB.
         b. **Dev Isolation (D-15)**: In development environment, if the template is not found in the DB, the system must continue using TypeScript templates without interruption.
         c. **Strict Error Handling (D-16)**: If the template is corrupt or DB fetch fails, log the error and throw an exception to abort the send process, preventing "broken" emails.
         d. **Auto Plain Text (D-11)**: If `body_text` is missing in the DB override, use `htmlToPlainText` utility to generate it from `body_html`.
         e. Interpolate `subject`, `greeting`, `body_html`, `preview`, and `body_text` using `substituirVariaveis`.
         f. Wrap the result in `renderEmailBase` (returning final HTML/Text).
         g. Return `null` if no override or inactive.
