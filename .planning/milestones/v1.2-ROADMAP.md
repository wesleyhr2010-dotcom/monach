## Overview

Elevar a qualidade do sistema em produção com testes E2E, observabilidade completa e proteção de endpoints.

## Phases

**Goal:** Cobrir o fluxo crítico da revendedora com testes end-to-end automatizados, garantindo regressão zero nos caminhos de negócio.
**Plans:** 3 plans

Plans:
- [x] 09-01: Playwright Setup & Seed (E2E-01, E2E-02)
- [x] 09-02: Golden Path Tests: Login → Maleta → Venda → Devolução (E2E-03..E2E-06)
- [x] 09-03: Recovery, CI/CD & Documentation (E2E-07..E2E-09)

**Goal:** Ter visibilidade total do comportamento do sistema em produção, com alertas proativos e zero vazamento de PII.
**Plans:** 4 plans

Plans:
- [x] 10-01: Sentry SDK Setup + Health Endpoint (OBS-01, OBS-06)

**Goal:** Proteger endpoints sensíveis contra abuso e brute-force sem impactar usuários legítimos.
**Plans:** 3 plans

Plans:
- [x] 11-01: Infrastructure & Public Endpoints: Upstash SDK, IP-based limits on /api/track, 429 responses (RATE-01, RATE-02, RATE-04, RATE-05)
- [x] 11-02: Authenticated Endpoints & Admin Bypass: userId limits on /api/upload-r2, admin/COLABORADORA bypass (RATE-03, RATE-06)
- [x] 11-03: Tests & Documentation: unit/integration tests, RATE_LIMITS.md, SPEC update (RATE-07)

- Decision: Limit Rate Limiting up to user and IP-based checks avoiding DB lock mechanisms.
- Decision: Write E2E Playwright tests explicitly for the golden paths.
