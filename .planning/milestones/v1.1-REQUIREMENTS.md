## Vitrina Pública

- [x] **VITR-01**: Cliente pode acessar vitrina pública via URL `/vitrina/{slug}`
  - *Outcome:* Implementado com ISR (revalidate=300) e `generateMetadata`
- [x] **VITR-02**: Vitrina exibe foto de perfil, nome e CTA WhatsApp da revendedora
  - *Outcome:* `VitrinaHeader` com avatar, nome, bio e botão WhatsApp
- [x] **VITR-03**: Vitrina exibe grid de produtos da maleta ativa com preços
  - *Outcome:* `ProductGrid` responsivo (2/3/4 cols) com `ProductCard`
- [x] **VITR-04**: Cada produto na grid é clicável e leva para página de detalhe
  - *Outcome:* Links para `/vitrina/{slug}/{produtoId}`
- [x] **VITR-05**: Slug inexistente ou revendedora inativa retorna 404
  - *Outcome:* `notFound()` para missing/inactive slugs
- [x] **VITR-06**: Sem maleta ativa exibe perfil + mensagem + CTA WhatsApp
  - *Outcome:* `EmptyState` com mensagem em espanhol paraguaio
- [x] **VITR-07**: SEO metadata gerada dinamicamente
  - *Outcome:* `generateMetadata` com título, descrição, OG tags, imagem perfil
- [x] **VITR-08**: Página usa `robots: noindex`
  - *Outcome:* `robots: 'noindex'` em todas as páginas da vitrina
- [x] **VITR-09**: Visitas rastreadas anonimamente com cookie
  - *Outcome:* Cookie `mnrc_vid` (30 dias, SameSite=Lax) via middleware
- [x] **VITR-10**: Eventos de checkout WhatsApp rastreados
  - *Outcome:* Evento `clique_whatsapp` via `/api/vitrina/track`
- [x] **VITR-11**: API de tracking com whitelist de eventos
  - *Outcome:* Endpoint aceita apenas `catalogo_revendedora`, `clique_whatsapp`
- [x] **VITR-12**: RLS permite leitura anônima
  - *Outcome:* Policies `maletas_anon_read_active` e `maleta_itens_anon_read_active`
- [x] **VITR-13**: Página de detalhe exibe fotos, descrição e botão "Agregar al carrito"
  - *Outcome:* `ProductDetailView` com image, name, price, description, add-to-cart
- [x] **VITR-14**: Produtos na grid levam para página de detalhe
  - *Outcome:* `ProductCard` links para `/vitrina/{slug}/{variantId}`
- [x] **VITR-15**: Carrinho em localStorage
  - *Outcome:* Estrutura `{ items: [{ productId, variantId, name, price, quantity, image }] }`
- [x] **VITR-16**: Badge flutuante sticky com contador
  - *Outcome:* `CartBadge` fixed bottom-right com `z-50`
- [x] **VITR-17**: "Finalizar pedido" gera mensagem WhatsApp
  - *Outcome:* `buildWhatsAppMessage()` com lista + total, truncado a ~2000 chars

- [x] **ANLT-03**: Ranking de revendedoras por engajamento
  - *Outcome:* `AnalyticsVitrinaRanking` com top 3 em gold

  - *Outcome:* Recharts BarChart com gradient fill e tooltip dark
