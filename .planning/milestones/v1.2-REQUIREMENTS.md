# Requirements: NEXT-MONARCA v1.2 (ARCHIVE)

**Defined:** 2026-05-06
**Core Value:** Revendedoras conseguem receber, registrar vendas e devolver maletas com comprovante — e receber a comissão calculada automaticamente.

## v1 Requirements

### E2E Testing
- [x] **E2E-01**: Playwright instalado e configurado com projeto Next.js (App Router) — Validated Phase 9
- [x] **E2E-02**: Seed script de banco para cenários de teste (usuário, maleta, produtos) — Validated Phase 9
- [x] **E2E-03**: Golden path — revendedora faz login com email/senha — Validated Phase 9
- [x] **E2E-04**: Golden path — revendedora visualiza maleta ativa — Validated Phase 9
- [x] **E2E-05**: Golden path — revendedora registra uma venda — Validated Phase 9
- [x] **E2E-06**: Golden path — revendedora registra devolução com comprovante — Validated Phase 9
- [x] **E2E-07**: Teste de recuperação de senha via email (fluxo completo) — Validated Phase 9
- [x] **E2E-08**: CI/CD roda suite E2E em PR (GitHub Actions) — Validated Phase 9
- [x] **E2E-09**: Documentação de como rodar E2E localmente — Validated Phase 9

### Observabilidade
- [x] **OBS-01**: Sentry integrado ao projeto Next.js (client + server) — Validated Phase 10
- [x] **OBS-02**: Erros de Server Actions reportados ao Sentry com contexto (userId, action name) — Validated Phase 10
- [x] **OBS-03**: Logs estruturados em JSON em todos os ambientes (desenvolvimento e produção) — Validated Phase 10
- [x] **OBS-04**: PII nunca aparece em logs de erro ou traces (sanitização via helper existente) — Validated Phase 10
- [x] **OBS-05**: Alerta Sentry quando taxa de erro > threshold configurado (ex: 1% das requisições) — Validated Phase 10
- [x] **OBS-06**: Dashboard Sentry com release tracking (associação commit ↔ erro) — Validated Phase 10
- [x] **OBS-07**: Performance monitoring — web vitals (LCP, FID, CLS) no Sentry — Validated Phase 10

### Rate Limiting
- [x] **RATE-01**: Middleware de rate limiting configurado via Upstash Redis — Validated Phase 11
- [x] **RATE-02**: Limite por IP em endpoints públicos (login, reset senha, API vitrina) — Validated Phase 11
- [x] **RATE-03**: Limite por userId em endpoints autenticados (mutações de maleta, venda) — Validated Phase 11
- [x] **RATE-04**: Headers de rate limit expostos (`X-RateLimit-Remaining`, `Retry-After`) — Validated Phase 11
- [x] **RATE-05**: Resposta 429 com mensagem amigável em espanhol paraguaio — Validated Phase 11
- [x] **RATE-06**: Rate limiting não impacta requisições legítimas de admin em uso normal — Validated Phase 11
- [x] **RATE-07**: Documentação dos limites e estratégia de burst — Validated Phase 11
